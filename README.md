# Customer Churn Prediction Web Application

This is a customer churn prediction web application built using **Streamlit**, **RandomForestClassifier**, and **Python**. It predicts whether a customer will churn based on historical data and displays insightful visualizations.

## Features

- **Login Page**: Secure login functionality to access the app.
- **Dataset Results**: Displays key insights, feature importance, churn distribution, and churn prediction visualizations.
- **User Input Prediction**: Allows users to input customer data and predict if they will churn, along with generating a downloadable PDF report.
- **Bulk Prediction**: Upload a CSV file for bulk customer predictions and download the results.

## Technologies Used

- **Streamlit**: For creating the web application.
- **Pandas**: For data handling and manipulation.
- **Scikit-learn**: For machine learning model (Random Forest).
- **Matplotlib & Seaborn**: For visualizations.
- **ReportLab**: To generate PDF reports.
